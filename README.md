Entry for the [make.fun](https://make.fun) competition
**"Make the AI judge feel awe"** (`make-the-ai-judge-feel-awe-20261121-1600`).

## What it does

`main.py` (Python 3.13, standard library only) writes one short text —
chosen by local pairwise judging against the competition's own relaxation
brief — to `/output/entry.txt`. The text is 1–280 characters, deterministic,
and needs no network or API key.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
